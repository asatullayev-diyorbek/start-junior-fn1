External CSS

External CSS nima?

External CSS — bu stillarni alohida style.css fayliga yozish usuli hisoblanadi. HTML fayli esa <link> tegi orqali ushbu CSS faylini ulaydi.

Afzalliklari

  • Kod tartibli bo'ladi.
  • Bitta CSS fayli bir nechta HTML sahifasida ishlatiladi.
  • Kodni tahrirlash va qo'llab-quvvatlash osonlashadi.
  • Loyihalar professional ko'rinishga ega bo'ladi.

Qanday ulanadi?

HTML faylining <head> qismiga quyidagi kod yoziladi:

<link rel="stylesheet" href="style.css">
